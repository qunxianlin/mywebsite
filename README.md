# MyWebsite - 我的第一個個人網站

> 這是一個使用 HTML 與 CSS 建立的個人首頁專案，作為學習 Git 與 GitHub 版本控制的第一個實作成果。

---

## 專案介紹 (Project Description)

* **為什麼製作這個專案？**  
  學習網頁前端基礎知識與 Git / GitHub 完整版本控制流程（包括檔案變更、暫存、提交、推送、版本回退以及撰寫專業的說明文件）。
* **這個專案解決什麼問題？**  
  提供一個結構清晰、輕量乾淨的個人首頁模板，並實踐以 GitHub 進行程式碼托管與版本管理的標準流程。
* **主要目標：**  
  熟悉現代軟體開發中必備的 Git 工作流，建立良好的開源專案維護習慣。

---

## 功能 (Features)

* [x] **個人資訊展示**：清晰呈現網站主標題與作者名稱
* [x] **簡約外觀樣式**：使用 CSS 設計清爽的淺藍色背景與現代字體
* [x] **響應式基礎標籤**：配置 viewport meta 標籤以支援跨裝置瀏覽
* [x] **完整 Git 版本控制**：包含多個清晰的 Commit 記錄
* [x] **排除不必要檔案**：配置 `.gitignore` 忽略系統與環境檔案

---

## 使用技術 (Technologies Used)

* **HTML5**：網頁結構與語意化標籤
* **CSS3**：版面美化、字體與背景樣式設計
* **Git**：本機版本控制與版本歷史管理
* **GitHub**：雲端遠端程式碼倉庫托管

## 使用方式 (How to Use)

你可以透過以下步驟在本地端瀏覽與運行這個專案：

### 1. 下載專案 (Clone)
使用 `git clone` 指令將專案複製到本機：

```bash
git clone https://github.com/qunxianlin/mywebsite.git
```

### 2. 進入專案資料夾
```bash
cd mywebsite
```

### 3. 開啟網頁
* **直接開啟**：在檔案總管中雙擊 `index.html` 即可在預設瀏覽器中開啟。
* **使用 VS Code**：在 VS Code 中安裝擴充套件 `Live Server`，並點擊右下角的 **Go Live** 即時預覽。
